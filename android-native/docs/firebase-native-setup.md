# Firebase Native Setup

The native Android app is intentionally separate from the existing Capacitor app.

Current native package:

```text
com.hsmocap.app
```

To complete Firebase Native Auth and Firestore integration:

1. Open Firebase Console for project `hsmocap-d907e`.
2. Add an Android app with package name `com.hsmocap.app`.
3. Add the debug SHA fingerprints for this Android project.
4. Enable Firestore for the project.
5. Download `google-services.json`.
6. Place it at:

```text
android-native/app/google-services.json
```

7. Enable the Android auth providers needed by the app:
   - Anonymous sign-in for guest mode
   - Email/password sign-in
   - Google sign-in after adding SHA-1/SHA-256 fingerprints
8. Re-download `google-services.json` after enabling Google sign-in so it contains the OAuth client data.
9. Rebuild the native app. `NativeServices` automatically selects Firebase implementations when the Firebase app initializes successfully.
10. Verify email/password, anonymous sign-in, Google sign-in, and Firestore study-state restore from the emulator.

## Local Readiness Check

Run these from `android-native`:

```powershell
.\gradlew.bat signingReport
.\gradlew.bat :app:firebaseReadiness
.\gradlew.bat assembleDebug
```

Use the `debug` variant SHA-1 and SHA-256 values from `signingReport` in Firebase Console.
Use `:app:firebaseReadiness` before and after adding `google-services.json`; it reports whether the config file exists, whether it contains the Android package `com.hsmocap.app`, and whether the Google Web client ID is present.

The Firebase config file must be exactly here:

```text
android-native\app\google-services.json
```

Before that file exists, the Settings screen should report local mode:

```text
백엔드 상태
로컬 모드 · Google 로그인 설정 대기
로컬 저장소 사용 중 · google-services.json 필요
설정 파일 없음 · Firebase 초기화 대기 · Web client ID 없음
```

After the file is added and the APK is rebuilt, the Settings screen should report Firebase readiness:

```text
백엔드 상태
Firebase 연결됨
설정 파일 감지됨
Firebase 초기화됨
Web client ID 있음
```

## Emulator Verification

Install a fresh debug build:

```powershell
adb -s emulator-5554 install -r app\build\outputs\apk\debug\app-debug.apk
adb -s emulator-5554 shell pm clear com.hsmocap.app
adb -s emulator-5554 shell am start -n com.hsmocap.app/.MainActivity
```

Or run the bundled Gradle task while an emulator is connected:

```powershell
.\gradlew.bat :app:androidDeviceDoctor
.\gradlew.bat :app:connectedDeviceCheck
.\gradlew.bat :app:installFreshDebug
.\gradlew.bat :app:runtimeSmokeCheck
```

Then verify this flow:

1. Guest login opens Home and creates an anonymous Firebase user.
2. Email sign-up, logout, and email login work with the same account.
3. Favoriting a word survives app restart.
4. A wrong quiz answer appears in Review and survives app restart.
5. Google login opens Home without falling back to local mode.

## Firestore Rules

Use user-scoped rules before testing real accounts:

```text
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

Suggested Firestore layout:

```text
users/{uid}
users/{uid}/studyState/current
```

Suggested `studyState/current` fields:

```text
favorites: number[]
wrongAnswers: number[]
notificationsEnabled: boolean
totalAnswered: number
correctAnswered: number
todayDate: string
todayAnswered: number
lastStudyDate: string
streakDays: number
updatedAt: server timestamp
```

Implemented native classes:

```text
app/src/main/java/com/hsmocap/app/auth/FirebaseAuthService.kt
app/src/main/java/com/hsmocap/app/auth/GoogleCredentialSignIn.kt
app/src/main/java/com/hsmocap/app/data/FirebaseStudyStore.kt
app/src/main/java/com/hsmocap/app/NativeServices.kt
```

`FirebaseStudyStore` reads the remote document on startup, merges it with local offline state, then writes the merged state back to Firestore.
Successful study sync updates the local `sync_metadata` table.
`FirebaseWordRepository` reads the `words` collection, upserts it into Room, and updates `sync_metadata` for the word catalog.
`GoogleCredentialSignIn` uses Android Credential Manager and `default_web_client_id`; that string is generated by the Google Services Gradle plugin from `google-services.json`.

Until `google-services.json` exists, the native app keeps using local fallback services so the project remains buildable in Android Studio.

## Troubleshooting

- `설정 파일 없음`: `google-services.json` is missing or not placed under `android-native\app`.
- `Web client ID 없음`: enable Google sign-in, add SHA fingerprints, then download `google-services.json` again.
- `Firebase 초기화 대기`: confirm the Firebase Android app package is `com.hsmocap.app`.
- Google sign-in fails after account selection: check SHA-1/SHA-256 and the Google provider in Firebase Authentication.
- Firestore does not restore study state: check Firestore rules, signed-in UID, and that the app is not still in local mode.
