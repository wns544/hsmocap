# 시연 마감 체크리스트 - 2026-05-16

## 현재 목적

캡스톤 전시/시연 전에 앱이 "테스트용 화면"처럼 보이지 않도록 커뮤니티 문구, 복습 문구, 샘플 게시글 데이터를 정리했다. 이번 작업은 기능을 크게 새로 늘리는 것이 아니라, 이미 구현된 커뮤니티와 복습 흐름을 더 설명 가능하고 안정적인 시연 상태로 다듬는 데 초점을 둔다.

## 이번 작업 범위

- 커뮤니티 게시글 상세 화면의 임시/어색한 문구를 자연스러운 한국어로 정리했다.
- 저장, 좋아요, 댓글, 수정, 삭제, 이미지 표시 흐름의 사용자 안내 문구를 정리했다.
- 복습 목록 화면의 제목, 카운트, 빈 상태, 시작 버튼 문구를 시연용으로 다듬었다.
- 커뮤니티 샘플 데이터 시드 스크립트를 영어 학습 서비스 주제에 맞는 글/댓글로 교체했다.
- 프론트엔드 빌드와 Functions 타입 빌드를 통과했다.

## 시연 전 데이터 준비

커뮤니티 샘플 글을 다시 깔끔하게 넣고 싶으면 아래 명령을 실행한다.

```powershell
cd C:\hsmocap\onejun_branch\functions
npm.cmd run seed:community
```

이 스크립트는 기존 `posts` 문서와 각 게시글의 `comments`, `likes`를 정리한 뒤, 전시용 샘플 게시글과 댓글을 다시 넣는다. 실제 운영 데이터가 있을 때는 실행 전에 반드시 확인해야 한다.

## 커뮤니티 시연 흐름

1. 로그인 후 커뮤니티 탭으로 이동한다.
2. 자유/질문/후기 카테고리별 게시글 목록을 보여준다.
3. 게시글 상세에서 좋아요, 저장, 댓글 작성, 댓글 수정/삭제를 보여준다.
4. 글 작성 화면에서 이미지 첨부가 가능하다는 점을 보여준다.
5. 즐겨찾기 탭의 게시글 영역에서 저장한 게시글이 모이는 흐름을 보여준다.

## 복습 시연 흐름

1. 문장 퀴즈에서 일부 단어를 틀리거나 `모르겠음`으로 처리한다.
2. Firestore의 `users/{uid}/wordProgresses/{wordId}`에 오답/복습 기록이 쌓이는 것을 설명한다.
3. 복습하기 화면에서 오늘 복습할 단어 수와 전체 복습 대기 수를 보여준다.
4. 오늘 복습 시작 버튼으로 기존 문장 퀴즈 화면을 재사용해 복습 세션에 진입한다.
5. 복습에서 정답 처리 후 `nextReviewAt`, `currentStage`, `lastResult`가 갱신되는 구조를 설명한다.

## 아직 남은 점검

- 실제 브라우저 QA는 별도로 진행해야 한다.
- 라이브 반영은 `onejun` 브랜치를 확인한 뒤, 사용자의 승인 후 `main` 병합 및 Firebase Hosting 배포로 진행한다.
- 이미지 힌트 품질은 개선됐지만, 외부 검색 결과 특성상 완전히 찰떡 이미지가 보장되지는 않는다.
- Functions 런타임은 현재 Node.js 20이며, 추후 Node.js 22 업그레이드 작업을 따로 잡는 것이 좋다.
