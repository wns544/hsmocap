3. 커뮤니티 기능 구현 범위
커뮤니티는 Firestore 실데이터 기반으로 동작하도록 연결했다.

구현된 기능:
- 카테고리 목록 조회
- 카테고리별 게시글 목록 조회
- 게시글 상세 조회
- 게시글 작성
- 댓글 목록 조회
- 댓글 작성
- 좋아요 토글
- 본인 게시글 삭제
- 본인 댓글 삭제
- 최소 권한 제어(Firestore Rules)

구현 의도:
- UI를 크게 바꾸지 않고 기존 커뮤니티 화면에 실데이터만 연결하는 방향으로 구현했다.
- 목록 -> 상세 -> 댓글/좋아요 -> 삭제 흐름을 우선 보장하는 MVP 방식으로 진행했다.

Firestore 구조:
- boardCategories/{categoryId}
- posts/{postId}
- posts/{postId}/comments/{commentId}
- posts/{postId}/likes/{uid}
- users/{uid}

커뮤니티에서 아직 후순위로 남겨둔 것:
- 게시글 수정
- 댓글 수정
- 게시글 저장(bookmark) 정식화
- 이미지 업로드 고도화
- 정확한 likeCount/commentCount/viewCount 집계 안정화
- 대댓글
- 신고/관리자 기능

4. 복습 기능 구현 범위
복습은 "새 단어를 다시 보여주는 기능"이 아니라 "사용자가 틀렸거나 아직 약한 단어를 다시 풀게 하는 기능"으로 구현했다.
기존 학습/문장퀴즈 UI를 재사용하고, 내부 데이터 흐름만 review mode로 연결했다.

구현된 핵심 흐름:
1) 사용자가 문장퀴즈를 푼다.
2) 정답/오답 결과를 Firestore의 wordProgresses에 저장한다.
3) 홈/복습 화면에서 복습 대상 단어를 불러온다.
4) 사용자가 복습 시작을 누르면 기존 SentenceQuiz 화면이 review mode로 열리고 복습 대상만 다시 푼다.
5) 복습 결과에 따라 currentStage, lastResult, nextReviewAt이 다시 갱신된다.

복습 대상 기준:
- 최근 오답 단어
- nextReviewAt <= now 인 단어
- 아직 MASTERED가 아닌 단어
- 약한 단어(정답률/결과 기준)

모르겠음 버튼 처리:
- 처음에는 모르겠음이 단순 정답 공개 성격이었으나, 마지막 보강으로 모르겠음도 오답 복습으로 기록되게 수정했다.
- 같은 문제에서 반복해서 모르겠음을 눌러 중복 오답이 누적되지 않도록 방지했다.

5. 복습 데이터 구조
최종 저장 경로:
- users/{uid}/wordProgresses/{wordId}

주요 필드:
- wordId
- status
  - NOT_STARTED
  - LEARNING
  - REVIEW
  - MASTERED
- currentStage
- totalAnswerCount
- correctAnswerCount
- lastReviewedAt
- nextReviewAt
- lastResult
  - correct
  - wrong
- createdAt
- updatedAt

복습 진행 규칙(현재 버전):
- 오답이면:
  - lastResult = wrong
  - status = REVIEW
  - currentStage = 1
  - nextReviewAt = now + 1 day
- 복습 모드에서 정답이면:
  - currentStage 증가
  - stage 2면 nextReviewAt = now + 3 days
  - stage 3면 nextReviewAt = now + 7 days
  - stage 4 이상이면 MASTERED 처리 및 nextReviewAt = null

6. Firestore 콘솔에서 확인할 위치
복습 데이터는 기존 예전 구조인 word_progress가 아니라, 새 camelCase 구조인 wordProgresses에 저장된다.

확인 경로:
- users/{uid}/wordProgresses/{wordId}

중요한 점:
- Authentication 사용자 수와 Firestore users 문서 수는 자동으로 일치하지 않는다.
- 이를 확인하기 쉽게 하기 위해, 복습 저장 시 users/{uid} 부모 문서가 자동 생성되도록 보강했다.

7. 로컬/로그인/CORS 관련 백 로직 보강
1) Google 로그인 보강
- Login.tsx에서 Google popup 실패 시 redirect fallback을 추가했다.
- unauthorized-domain 문제 시 더 명확한 안내를 띄우도록 수정했다.

2) 로컬 127.0.0.1 CORS 허용
- Functions allowed origins에 http://127.0.0.1:5173 을 추가했다.
- 재배포한 함수:
  - gradeWordAnswerHttpV3
  - imageHintSearchHttp

3) 결과
- 로컬 개발 서버에서 127.0.0.1:5173 기준으로도 서버 채점과 이미지 힌트 호출이 403 없이 200으로 동작하도록 복구했다.

8. QA에서 확인된 사항
직접 확인된 것:
- gradeWordAnswerHttpV3가 200으로 정상 응답
- 오답 제출 후 /app/review에 해당 단어가 복습 대상으로 뜸
- Firestore users/{uid}/wordProgresses/{wordId}에 wrong 상태 저장됨
- review mode로 다시 들어가 정답을 맞추면:
  - lastResult가 correct로 바뀜
  - currentStage가 증가함
  - nextReviewAt이 뒤로 밀림
- 모르겠음 버튼도 오답 복습으로 기록되도록 반영 완료

즉 현재 복습 기능은 핵심 흐름 기준으로 운영 가능한 수준까지 완료된 상태다.
